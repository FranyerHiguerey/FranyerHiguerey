## Wondering why this profile looks so quiet?

Fair question. Two reasons, and I'd rather just tell you than have you guess.

Almost everything I've worked on belongs to a client or the company, so it lives in private repos. I'd rather keep it that way than publish code that isn't mine to share.

And a good chunk of my work over the years happened on GitLab, not here. So if you scroll down to my contribution graph, you'll find some pretty empty-looking years that were actually some of my busiest.

Which means this profile won't tell you much on its own — and I'd rather say so than pretend otherwise. If you want to see how I really work, I'm glad to hop on a call and walk you through the architecture behind any of it, or put together a code sample for whatever you'd need to see.
